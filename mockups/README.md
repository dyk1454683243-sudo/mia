# Lookbook mockups

Design exploration for the Mia table UI, September 2026. **Nothing here is
shipped or decided** — these are pitches, referenced from the issues they
belong to.

This directory lives only on the `design/lookbook-assets` branch so the images
have a stable public URL for embedding in GitHub issues. It is deliberately not
merged into `main`.

- `lookbook.html` — the whole board. Open it in a browser; every mockup is live
  HTML and CSS, not a picture.
- `NN-*.png` — one plate each, rendered at 2× from `lookbook.html`.
